# Ch'hal Daro

Scores football en temps réel — Next.js 16, TheSportsDB, Supabase, notifications push.

**Version 0.1.0** · branche de release **`v0.1`**

## Documentation

## Démarrage rapide

```bash
npm install
cp .env.example .env.local   # puis renseigner les clés
npm run dev
```
